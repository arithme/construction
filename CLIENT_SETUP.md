# Client setup

1. Put the logo in `public/`.
2. Edit `client.config.ts` with the company name, logo, phone, services, projects and colors, or run `npm run create-client`.
3. Edit `client.advanced.config.ts` for contact details, service areas, analytics and demo mode.
4. Add verified project images and facts.
5. Add only verified credentials, statistics and testimonials.
6. Configure forms and analytics from `.env.example`.
7. Run lint, type checks, tests and the production build.
8. Complete `PRODUCTION_CHECKLIST.md`, connect the domain and deploy.

JSON import: `npm run create-client -- --from clients/aranya-buildcon.json`. Existing configuration is never overwritten without confirmation.
